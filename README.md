# Skills

Claude Code skills.

**interview-research:** builds evidence-backed Google Doc prep for interviews. Daily mode preps every interview on your calendar for a day; panel mode builds one doc per interviewer from a shared schedule. See `interview-research/SKILL.md`. Copy `settings.example.md` to `settings.md` and fill in your own details before use.

To install, copy the `interview-research` folder into `~/.claude/skills/`.

## How to use it

To prepare for a phone screen or onsite, paste this into ChatGPT, Claude or a similar assistant:

```
Run this skill https://github.com/MeghnaNatraj/Skills/blob/main/interview-research/SKILL.md, along with any other information or attached artifacts below: <PASTE YOUR SCHEDULE HERE OR ATTACH IT AS A SCREENSHOT>
```

The schedule needs the company name and, for each interview, the interviewer's name and the interview topic.

**Result:** it creates one prep doc per interviewer, like [this example](https://drive.google.com/drive/folders/1fK8aj7sDxEQnoGKuP4maFPmsnva51Uat).
